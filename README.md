# Node.js HTTP Server

This is my first basic Node.js project. In this project, I created a simple HTTP server using Node.js.

## Features

* Created an HTTP server using Node.js
* Server runs on port `2222`
* Displays a simple response in the browser

## How to Run

```bash
node index.js
```

Then open:

```text
http://localhost:2222
```
